### 步骤5：配置SysTick中断

**在stm32f4xx_it.c中，确保SysTick_Handler正确：**

```c
void SysTick_Handler(void)
{
  /* USER CODE BEGIN SysTick_IRQn 0 */

  /* USER CODE END SysTick_IRQn 0 */
  HAL_IncTick();
  /* USER CODE BEGIN SysTick_IRQn 1 */
  // 这里会自动调用任务调度器
  /* USER CODE END SysTick_IRQn 1 */
}
```

### 步骤6：添加任务调度器

**创建 Core/Src/app_task_scheduler.c：**

```c
/**
 * @file app_task_scheduler.c
 * @brief 任务调度器 (由SysTick驱动)
 */

#include "main.h"

/* 任务标志变量 (在main.c中声明) */
uint8_t s_task10msFlag = 0;
uint8_t s_task100msFlag = 0;
uint8_t s_task1000msFlag = 0;

static uint32_t s_task10msCounter = 0;
static uint32_t s_task100msCounter = 0;
static uint32_t s_task1000msCounter = 0;

/**
 * @brief App系统初始化
 * @note 由main.c调用
 */
void App_System_Init(void)
{
    s_task10msCounter = 0;
    s_task100msCounter = 0;
    s_task1000msCounter = 0;
}

/**
 * @brief App任务调度器初始化
 */
void App_TaskScheduler_Init(void)
{
    // 初始化已在App_System_Init中完成
}

/**
 * @brief SysTick中断处理 (1ms调用一次)
 * @note 由HAL库自动调用，从SysTick_Handler中调用
 */
void HAL_SYSTICK_Callback(void)
{
    // 这个函数会在每个HAL_IncTick()后自动调用
    // 默认1ms调用一次
    
    s_task10msCounter++;
    if (s_task10msCounter >= 10) {
        s_task10msCounter = 0;
        s_task10msFlag = 1;  // 标记10ms任务可以运行
    }
    
    s_task100msCounter++;
    if (s_task100msCounter >= 100) {
        s_task100msCounter = 0;
        s_task100msFlag = 1;  // 标记100ms任务可以运行
    }
    
    s_task1000msCounter++;
    if (s_task1000msCounter >= 1000) {
        s_task1000msCounter = 0;
        s_task1000msFlag = 1;  // 标记1000ms任务可以运行
    }
}
```

## 🔧 故障排查

### 问题1：无法识别W25Q16

**症状**：`[NVM] W25Q16识别失败!`

**原因**：SPI通信问题

**解决**：
1. 检查PB3/PB4/PB5是否正确配置为SPI1
2. 检查PB0 CS引脚是否正确配置为GPIO_Output
3. 检查JTAG是否已关闭（应该只保留SWD）
4. 尝试降低SPI波特率到更低值

### 问题2：按键无响应

**症状**：`[KEY] 按键初始化完成` 但按键无输出

**原因**：EXTI中断未配置或处理不当

**解决**：
1. 检查PE3/PE4是否配置为GPIO_Input + EXTI
2. 检查EXTI中断是否在NVIC中Enable
3. 检查stm32f4xx_it.c中是否有HAL_GPIO_EXTI_IRQHandler调用

### 问题3：CAN不工作

**症状**：`[CAN] CAN1启动成功` 但无法发送/接收

**原因**：CAN硬件未启用中断或总线问题

**解决**：
1. 检查CAN1_RX0中断是否在NVIC中Enable
2. 检查是否连接了CAN收发器 (SN65HVD230或SIT1042T)
3. 检查CAN总线两端是否有120Ω终端电阻
4. 用示波器检查CAN_RX和CAN_TX引脚波形

### 问题4：温度传感器读数不变

**症状**：ADC值始终是0或固定值

**原因**：ADC采样未启动或转换未完成

**解决**：
1. 确认`HAL_ADC_Start(&hadc1)`已调用
2. 检查PE5/PC5温度传感器引脚是否接入
3. 检查ADC1中断是否Enable
4. 在HAL_ADC_ConvCpltCallback中添加printf调试

## 🎯 各功能测试方法

### PWM测试

```bash
# 预期行为:
1. LED应该从暗逐渐变亮，然后逐渐变暗 (呼吸效果)
2. 马达应该逐步加速（0% → 100%）
3. 马达应该定期改变方向（每2秒）

# 用万用表或示波器验证:
- 使用电压表: LED_PWM (PD12) 电压应该0-3.3V变化
- 使用示波器: 应该看到1kHz PWM波形，占空比逐步变化
```

### CAN测试

```bash
# 方法1: 使用逻辑分析仪或示波器
- 连接到CAN_RX (PB8) 和 CAN_TX (PB9)
- 应该看到CAN波形

# 方法2: 使用两个ECU自收自发
- VCU模拟器发送报文到 ECU
- ECU应该收到并回显

# 预期消息:
- ID: 0x123, Data: 01 02 03 04 05 06 07 XX (每100ms)
```

### 按键测试

```bash
# 预期行为:
1. 按下K0: 输出 "[KEY] K0 按下 Xms"
2. 按住K0超过3秒: 输出 "[KEY] K0 卡滞!"
3. 按下K1: 输出 "[KEY] K1 按下 Xms"

# 用示波器验证中断频率:
- EXTI3 (K1) 和 EXTI4 (K0) 应该在按键时触发
```

### 温度传感器测试

```bash
# 预期行为:
1. 正常工作时: 输出当前温度，如 "[ADC] 温度: 25.50℃"
2. 温度值范围应该在 -40℃ 到 +125℃ 之间
3. 触摸温度传感器引脚，温度值应该上升

# 用热枪验证:
- 加热传感器到50℃，应该显示接近的温度
- 冷冻传感器到0℃，应该显示接近的温度
```

### NVM测试

```bash
# 预期行为:
1. 识别W25Q16: "[NVM] W25Q16识别成功 (EF=Winbond, 40=16M)"
2. 写入VIN: 数据应该成功写入
3. 读取VIN: 读回的VIN应该与写入的一致
4. 测试完成: "[NVM] 测试完成"

# 验证方式:
- 在串口中看到上述输出则为成功
- 可以用逻辑分析仪观察SPI时序
```
