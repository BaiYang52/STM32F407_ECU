## 📋 立即操作指南

### 第1步：复制测试文件 (5分钟)

**从"STM32F407_基础功能快速集成指南.md"中：**
- 复制5个测试文件 (test_pwm.c 等) 到 Core/Src/
- 复制5个头文件到 Core/Inc/
- 创建 app_task_scheduler.c 和 app_task_scheduler.h

### 第2步：集成到CubeIDE项目 (10分钟)

```bash
步骤:
1. 打开你的CubeIDE项目
2. 右键 Core/Src → Import Files → 选择test_*.c
3. 右键 Core/Inc → Import Files → 选择test_*.h
4. 修改main.c和main.h (参考快速集成指南)
5. 修改stm32f4xx_it.c中断处理
6. Build Project
```

### 第3步：验证编译 (5分钟)

```
预期: Build successful ✓

如果有错误:
- 检查include路径
- 检查文件是否正确复制
- 查看快速参考指南的故障排查
```

### 第4步：烧写并测试 (10分钟)

```bash
1. Run → Run (或F11)
2. 打开串口助手 (115200 bps)
3. 应该看到初始化输出
4. 按照"基础功能测试代码.md"中的测试步骤验证
```

### 第5步：调试各功能 (30-60分钟)

**按此顺序逐个验证：**

```
☐ PWM: LED应该呼吸，马达应该加速
☐ CAN: 应该看到周期性的0x123报文发送
☐ 按键: 按下时应该输出按键状态
☐ 温度: 应该看到温度值（-40 ~ +125℃范围）
☐ NVM: 应该识别W25Q16并成功读写
```
